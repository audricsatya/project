# Project 5: Deep Learning Forecasting Model with LSTM

This project utilizes an LSTM (Long Short-Term Memory) neural network to predict stock prices. The model effectively reads historical stock data and forecasts prices for several hours ahead, demonstrating strong predictive performance.

## What is LSTM?

LSTM is a type of recurrent neural network (RNN) designed to handle sequential data and capture long-term dependencies. It is especially effective for time series forecasting tasks, such as predicting stock prices.

### LSTM Gates

LSTM networks use special structures called gates—input, forget, and output gates—to control the flow of information. These gates help the model decide which information to keep, update, or discard, allowing it to learn complex temporal patterns in data.

## Features

- Uses LSTM for time series forecasting  
- Processes and learns from historical stock price data  
- Predicts future stock prices for short-term intervals

## Results

The LSTM model accurately captured patterns in the data and provided reliable short-term stock price forecasts.
